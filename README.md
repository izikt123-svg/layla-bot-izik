# GoTours Navigator v26 — ללא מפתחות

גרסה זו בנויה כך שלא צריך להעתיק או לשמור מפתחות של Firebase, Anthropic או Google.

## מה עובד ללא מפתחות

- מפות, GPS, ניווט, מה סביבי, מזג אוויר, GPX/KML/KMZ ומצב אופליין.
- הקראה בקול של המכשיר באמצעות Safari או Chrome — ללא שירות קול חיצוני.
- מרכז קבוצה, מיקומי מטיילים, צ׳אט, הודעות קוליות ואלבום באמצעות Netlify Functions ו-Netlify Blobs.
- מדריך חכם וזיהוי תמונות באמצעות Netlify AI Gateway.

## העלאה נכונה ל-Netlify

לפריסה מלאה של פונקציות הקבוצה והמדריך, חבר את התיקייה למאגר GitHub ובחר ב-Netlify: **Add new site → Import an existing project**. Netlify יתקין את התלות `@netlify/blobs` ויארוז את הפונקציות.

העלאה ידנית בגרירה יכולה להעלות את האתר הסטטי, אבל אינה מריצה Build ולכן אינה הדרך המומלצת לגרסה זו.

1. העלה את כל תוכן התיקייה למאגר GitHub.
2. ב-Netlify בחר Import from Git וחבר את המאגר.
3. אין צורך להוסיף Environment Variables או מפתחות.
4. בצע Deploy ייצור אחד.
5. ב-Netlify הפעל **AI Features / AI Gateway**. השירות עשוי להשתמש בקרדיטים של תוכנית Netlify שלך.
6. באתר פתח **🔧 בדיקת מערכת** וודא שמופיעים אישורים ל-AI, לקול ולקבוצה.

## פרטיות ואחסון

- מיקום, צ׳אט, קול ותמונות של קבוצה נשמרים זמנית ב-Netlify Blobs.
- קבוצה פוקעת ונמחקת אוטומטית לאחר 30 יום.
- הקול הרגיל מופק במכשיר ואינו נשלח לשירות קול חיצוני.
- שאלות ותמונות למדריך החכם מועברות דרך Netlify AI Gateway.
- אין לפרסם קוד קבוצה בפוסט פתוח; שולחים אותו רק למטיילים הרלוונטיים.

## בדיקה לפני שימוש עם מטיילים

- בדוק GPS, מיקרופון, מצלמה והרשאות באייפון אמיתי.
- פתח קבוצה בשני טלפונים ובדוק מיקום, צ׳אט, קול ואלבום.
- הורד מראש מפות לאזור הטיול ובדוק מצב טיסה.
- אין להסתמך על האפליקציה לבדה בהחלטות בטיחות או שיטפונות.
