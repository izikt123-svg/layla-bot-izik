# 01 — חזון ומבנה ראשי

## חזון המערכת

מערכת ניהול חכמה למשרד ייעוץ מס והנהלת חשבונות, המשלבת:

- CRM לקוחות
- ניהול תיקים
- ניהול משימות
- ניהול מסמכים
- גבייה
- WhatsApp מובנה
- דשבורדים
- הרשאות עובדים
- AI חכם
- פורטל לקוחות
- מערכת KPI
- SLA
- BI
- Mobile

**המטרה:** שליטה מלאה על כל פעילות המשרד בזמן אמת ממערכת אחת.
