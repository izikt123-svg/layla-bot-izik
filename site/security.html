אבטחה ופרטיות

המידע האישי שלך — בלעדית עליך. הנה כל מה שאנחנו עושים כדי לשמור עליו.

🔐 הגנות פעילות

  • 🔒 HTTPS בלעדי — כל התקשורת מוצפנת.
  • 🛡 HSTS שנה — הדפדפן מתעקש על HTTPS גם אם תקליד "http".
  • 🚫 X-Frame-Options: SAMEORIGIN — מונע הטמעה זדונית באתר אחר.
  • 🛂 Content Security Policy מחמיר — חוסם הזרקת קוד זר.
  • 🤖 Honeypot anti-bot בכל טופס — בוטים נחסמים בשקט.
  • ⏱ Rate Limiting 10–30 בקשות לדקה לכל IP — מונע הצפה.
  • 🔑 API Keys (Gemini / Stripe / Supabase) חיים רק בשרת — לעולם לא בדפדפן.
  • 🧹 XSS Sanitization — כל פלט משתמש עובר escape לפני הצגה.
  • 🗄 Supabase Row-Level Security מופעל — אין גישה ישירה לבסיס הנתונים מהדפדפן.
  • 🔍 Input Validation בשרת — לכל שדה אורך מקסימלי + סוג.
  • 📷 Permissions Policy — מצלמה כבויה כברירת מחדל.
  • 🌐 Cross-Origin Isolation — בידוד בין דפים פנימיים לחיצוניים.

📜 תקנים שאנו עומדים בהם

✓ OWASP Top 10 10 הסיכונים המובילים
✓ WCAG AA נגישות (חלקית)
✓ PCI DSS תרומות דרך Stripe
✓ HSTS HTTPS מחייב
✓ HSTS Preload מוכן ל-Google preload

📍 איפה המידע שלך נשמר?

  • סטריקים, נרות אישיים, ארכיון משפחתי → במכשיר שלך בלבד (localStorage). לעולם לא נשלח לשרת.
  • בקשות תפילה ציבוריות → Supabase (תוכן ציבורי, ללא זיהוי אישי אם בחרת אנונימי).
  • מספרים של בתי חב"ד → קבועים בקוד (פתוחים בכל GitHub).
  • שיחה עם מירב → נשלחת ל-Google Gemini עם פילטרים. לא נשמר.
  • תמונות נר → אופציונלית עולות ל-Supabase Storage.
