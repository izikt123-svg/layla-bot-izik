# 🕍 5 תמונות אמיתיות של מקומות קדושים בירושלים

האתר כבר עובד! גם בלי להעלות תמונות — רואים 5 איורים יפים מתחלפים.
**ברגע שתעלה תמונה אמיתית — היא תחליף את האיור אוטומטית.**

## 📤 איך מעלים? (3 דקות, ב-GitHub)

1. **לך ל-**: https://github.com/izikt123-svg/layla-bot-izik/tree/claude/review-files-iujbA/images/heroes
2. לחץ **"Add file"** → **"Upload files"**
3. **גרור את התמונות** (הורד מ-Wikipedia / מצלם בעצמך / ממקור חופשי)
4. **שמור עם השמות המדויקים האלה** (חשוב — אותיות קטנות באנגלית בלבד!):

| המקום הקדוש | שם הקובץ המדויק | הצעת מקור (חינמי) |
|-------------|------------------|---------------------|
| 🕍 הכותל המערבי | **`kotel.jpg`** | חיפוש בויקיפדיה: "Western Wall" |
| 🕌 הר הבית / כיפת הסלע | **`temple-mount.jpg`** | חיפוש: "Temple Mount" |
| ⛰ מערת המכפלה (חברון) | **`machpela.jpg`** | חיפוש: "Cave of Patriarchs" |
| 💎 קבר רחל (בית לחם) | **`rachel-tomb.jpg`** | חיפוש: "Rachel's Tomb" |
| 🏛 העיר העתיקה (ירושלים) | **`old-city.jpg`** | חיפוש: "Jerusalem Old City" |

5. למטה — לחץ **"Commit changes"** (כפתור ירוק)
6. **Netlify יעדכן אוטומטית** תוך דקה

## 🎯 גודל מומלץ לתמונה

- **רוחב**: 1400px (או יותר, האתר יקטין אוטומטית)
- **פורמט**: JPG (לא PNG — קל יותר לטעינה)
- **משקל**: עד 300KB לתמונה
- **יחס**: רוחב/גובה ≈ 16:9 (פנורמית) או 3:2

## ⚠️ אם השם לא מדויק — התמונה לא תופיע!

לפני העלאה, **שנה את שם הקובץ במחשב**:
- Windows: F2 → הקלד שם חדש → Enter
- Mac: Return → הקלד שם חדש → Return

## 🌍 איפה להוריד תמונות חינם?

1. **Wikimedia Commons** — https://commons.wikimedia.org (כל התמונות חופשיות לשימוש)
2. **Unsplash** — https://unsplash.com (חינמי לחלוטין)
3. **Pexels** — https://pexels.com
4. **תמונות אישיות שלך** — אם צילמת בכותל / בעיר העתיקה

## 🔄 איך הרוטטור עובד?

- ✦ קרוסל אוטומטי

- ✦ שם המקום מופיע בפינה
