# 🕯 Meirav — WhatsApp Bot

מירב בוואטסאפ — בוט שמחבר ישראלים ויהודים ברחבי העולם לשירותי האתר.

## איך מריצים

### על Render / VPS:
```bash
cd whatsapp-bot
npm install
SITE_URL=https://my-hom.net node index.js
```
QR code מופיע ב-logs. סורקים בוואטסאפ → Linked devices.

### משתני סביבה:
- `SITE_URL` — כתובת האתר (default: `https://my-hom.net`).
- `PORT` — פורט לבדיקת חיים (default: 10000).

## פקודות שהמשתמשים יכולים לשלוח

| פקודה | מה זה עושה |
|--------|-----------|
| `מירב` / כל שאלה | Gemini AI עונה |
| `תפילה <שם>` | מפרסם בקיר התפילות |
| `תפילה רפואה <שם>` | קטגוריית רפואה |
| `חבד <עיר>` | חיפוש בית חב"ד |
| `שעות שבת <עיר>` | זמני שבת מ-Hebcal |
| `תהילים` | קישור לתהילים יומי |
| `תרומה` | קישורי תרומה |
| `עזרה` / `?` | תפריט פקודות |

## קבוצות
הבוט עונה רק כשמזכירים אותו בשם "מירב" בתוך הודעה בקבוצה.

## אבטחה
- ה-Gemini API key לעולם לא חי בבוט — הבוט קורא ל-`/api/ai` של האתר.
- אין צורך לטעון מפתחות סודיים בבוט.
